# Fonts

Self-hosted (the CSP allows fonts from this origin only), Latin subset, variable weight, from the Fontsource
`@fontsource-variable/*` packages (5.3.0). The list the app offers is `lib/fonts.js`. Copyright lines are from
each package's own LICENSE file.

- **Geist**: Copyright 2024 The Geist Project Authors (https://github.com/vercel/geist-font)
- **Inter**: Copyright 2016 The Inter Project Authors (https://github.com/rsms/inter)
- **Manrope**: Copyright 2019 The Manrope Project Authors (https://github.com/sharanda/manrope)
