# Emoji

`public/emoji.json` (the reply box's emoji picker, `public/js/emoji.js`) is generated by `scripts/make-emoji.js` from
the `emojibase-data` package: each emoji with its name, keywords and GitHub shortcodes. The emoji themselves are
drawn by the visitor's own system font; nothing here is a picture.
