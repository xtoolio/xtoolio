# Fonts used server-side

`bricolage-grotesque-latin-wght-normal.ttf` is `public/fonts/bricolage-grotesque-latin-wght-normal.woff2`
(Bricolage Grotesque, Latin variable subset) decompressed to TTF, unchanged otherwise, for the circle's share image
(`services/circleImage.js`: resvg reads TTF/OTF, not WOFF2). It is under the SIL Open Font License 1.1, the same
terms as the web fonts: see `public/fonts/LICENSE.md`.
